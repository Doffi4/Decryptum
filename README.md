# DoffiSecure (Decryptum) 🔐

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com)
[![Language](https://img.shields.io/badge/Language-Kotlin-purple.svg)](https://kotlinlang.org)

**DoffiSecure** (також відомий як **Decryptum**) — це сучасний, безпечний та швидкий менеджер паролів з відкритим вихідним кодом для Android, створений із використанням Jetpack Compose та Clean Architecture.

---

## ✨ Основні можливості / Key Features

- 🛡️ **Локальна безпека та шифрування**: Ваші паролі зашифровані та зберігаються виключно локально на вашому пристрої.
- 🎲 **Генератор надійних паролів**: Гнучкі налаштування складності (довжина, великі/малі літери, цифри, спеціальні символи).
- 🔍 **Аналіз безпеки та пошук дублікатів**: Автоматичне виявлення повторюваних та слабких паролів для запобігання витокам даних.
- 🎨 **Сучасний UI на Jetpack Compose**: Інтуїтивний, плавний інтерфейс із підтримкою динамічних тем Material 3 та темного режиму.
- ⚡ **Швидкий пошук та сортування**: Миттєва фільтрація за назвою сервісу або логіном.

---

## 🛠️ Стек технологій / Tech Stack

- **Мова:** Kotlin
- **UI:** Jetpack Compose, Material 3
- **Архітектура:** Clean Architecture + MVVM + Use Cases
- **База даних:** Room (локальне сховище)
- **Впровадження залежностей (DI):** Dagger / Hilt
- **Асинхронність:** Kotlin Coroutines & StateFlow / SharedFlow

---

## 🚀 Як зібрати проєкт / Getting Started

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/Doffi4/Decryptum.git
   cd Decryptum
   ```
2. **Відкрийте в Android Studio:**
   - Виберіть `Open` і вкажіть на папку проєкту.
   - Зачекайте завершення Gradle Sync.
3. **Запустіть на емуляторі або реальному пристрої:**
   - Натисніть кнопку **Run** (`Shift + F10`) у панелі Android Studio.
